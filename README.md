# useful-school-portal

## General Information
* A useful school portal with many of the features you can find in education portal websites such as Blackbaud, including class creation, assignment creation, student grading, and report card development.
* The program uses a complex directory system to manage accounts, grades, and more.
* Developed between January and May 2025 (my junior year of high school) for a collegiate-level Object-Oriented Programming course. Had I had more experience, I would have developed an online cloud space to hold the directories to save hard drive space and allow multiple devices to access the same information without having to constantly download data from other users.

## Technologies
* This project was fully developed with base Java tools, leveraging use of the I/O readers and the java.awt graphics packages.

## Setup
* Run the "Run.java" file under the run package. You can begin by making an account representing a school institution and work from there.
